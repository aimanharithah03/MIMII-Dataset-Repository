# MIMII-Dataset-Repository
Files and Coding for MIMII related task

An early test-run of MIMII Dataset by Hitachi, Ltd. under a Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0) license. it is use to implement into an Edge device (Infineon PSoC6 CY8CKIT-062S2-AI) to detect anomaly sound in various machine component. Current code is focus on a single type of sound (Fan) on multiple machines (Machine ID_00, ID_02, ID_04, ID_06).
